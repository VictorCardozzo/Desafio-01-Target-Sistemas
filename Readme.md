# 🚀 Desafios Técnicos de Programação — Python

Este repositório reúne as soluções desenvolvidas para um processo seletivo técnico. O objetivo principal foi resolver três problemas práticos de lógica de negócios, processamento de dados e regras de cálculo utilizando a linguagem **Python**.

---

## 💡 Sobre a Abordagem Técnica

Todas as soluções foram implementadas priorizando o **domínio da lógica de programação** e o uso eficiente de estruturas nativas da linguagem, sem dependência de bibliotecas externas complexas.

### Principais Conceitos Aplicados:
* **Dicionários (`dict`)**: Utilizados para busca rápida ($O(1)$), agrupamento dinâmico de dados por chave e modelagem de registros estruturados.
* **Listas (`list`) e Iterações (`for` / `while`)**: Empregadas para manipulação de coleções, filtros, laços de repetição com menus interativos e controle de fluxo.
* **Manipulação de Datas (`datetime`)**: Utilizada no cálculo de prazos e diferenças de dias entre datas no calendário.
* **Estrutura de Regras de Negócio**: Aplicação rigorosa de condicionais (`if / elif / else`) para validação de estados (como saldo em estoque e faixas de comissão).
